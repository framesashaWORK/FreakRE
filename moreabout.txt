# freakRE - Платформа реверс-инжиниринга

## Общее описание
Проект представляет собой модульную платформу на Rust для статического и динамического анализа бинарных файлов. Архитектура построена на основе множества независимых крейтов (crates), каждый из которых отвечает за конкретную задачу: от парсинга форматов файлов до декомпиляции и эмуляции кода.

## Структура проекта

### Основные компоненты (Core Crates)

#### 1. Парсеры форматов файлов
- **pe-parser** - Парсер формата PE (Portable Executable) для Windows.
- **elf-parser** - Парсер формата ELF (Executable and Linkable Format) для Linux/Unix. Содержит модули для работы с заголовками, секциями, символами и программными заголовками.
- **macho-parser** - Парсер формата Mach-O для macOS/iOS.
- **coff-parser** - Парсер формата COFF (Common Object File Format).
- **dex-parser** - Парсер формата DEX (Dalvik Executable) для Android.
- **wasm-parser** - Парсер формата WebAssembly.

#### 2. Анализ и обработка кода
- **freakre-x86** - Декодер и форматтер инструкций x86/x64. Включает LDE (Length Disassembler Engine).
- **capstone-ffi** - FFI-обертка вокруг библиотеки Capstone для дизассемблирования различных архитектур.
- **freakre-ir** - Промежуточное представление (IR) кода. Включает лифтеры (lifters) для x86, ARM, MIPS, RISC-V, которые преобразуют машинный код в IR. Реализует SSA (Static Single Assignment) форму и оптимизации.
- **cfg-builder** - Построитель графов потока управления (Control Flow Graph).
- **dataflow** - Модуль анализа потоков данных. Включает анализ живых переменных (live variables), достигающих определений (reaching definitions), цепей use-def и анализ множеств значений (value set analysis).
- **type-system** - Система типов для восстановления типов данных в бинарном коде. Включает базу данных типов, вывод типов (inference) и печать типов.
- **type-propagation** - Распространение типов по графу потока управления.

#### 3. Декомпиляция
- **decompiler** - Основной движок декомпиляции. Преобразует IR в AST (Abstract Syntax Tree), а затем в C-подобный код. Включает:
  - Упрощение выражений (simplify)
  - Структурирование кода (structuring) - восстановление циклов и условий
  - Восстановление стековых переменных (stack_vars)
  - Межпроцедурный анализ (interproc)
  - Восстановление имен вызовов (call_naming)

#### 4. Эмуляция
- **emulator-x86** - Эмулятор процессора x86/x64 для динамического анализа. Включает управление памятью, состоянием регистров и выполнением инструкций.

#### 5. Анализ уязвимостей и вредоносного ПО
- **backdoor-analyzer** - Анализатор бэкдоров. Ищет подозрительные паттерны импортов, строк и данных.
- **shellcode-analyzer** - Анализатор шеллкодов. Определяет API хэши, обнаруживает техники обфускации.
- **behavior-detect** - Детектор поведения. Анализирует потенциально опасные действия кода.
- **import-analyzer** - Глубокий анализ таблиц импорта.
- **func-finder** - Поиск функций в бинарном коде с использованием рекурсивного спуска и сигнатур.
- **func-sigs** - База сигнатур известных функций.

#### 6. Сканеры и поиск
- **scanner** - Основной сканер файлов. Поддерживает вывод отчетов в различных форматах.
- **yara-lite** - Легковесная реализация правил YARA для поиска паттернов. Включает компилятор, парсер и сканер.
- **freakre-patterns** - Модуль поиска паттернов с использованием Aho-Corasick алгоритма и регулярных выражений.
- **str-extract** - Извлечение строк из бинарных файлов (ASCII, Unicode, wide strings).

#### 7. Вспомогательные модули
- **freakre-hash** - Реализации хеш-функций: MD5, SHA1, SHA256, CRC32, Murmur3.
- **entropy-rs** - Вычисление энтропии данных для обнаружения шифрования/упаковки.
- **gpu-scan** - Использование GPU для ускорения сканирования (через wgpu).
- **ml-detection** - Машинное обучение для классификации файлов. Извлекает фичи и использует классификатор.
- **diffing** - Сравнение бинарных файлов (binary diffing) на уровне графов вызовов.
- **xrefs** - Управление перекрестными ссылками (cross-references).
- **project-db** - База данных проекта на основе sled (embedded key-value store). Хранит функции, символы, комментарии и поддерживает undo/redo.
- **freakre-config** - Управление конфигурацией (JSON/TOML).
- **freakre-script** - Встроенный скриптовый язык для автоматизации задач. Включает лексер, парсер, интерпретатор и песочницу.
- **scripting** - Интеграция со скриптовыми движками.
- **plugins** - Система плагинов для расширения функциональности.
- **sys-plugins** - Системные плагины: анализ криптографии, энтропии, классификация функций, анализ строк.

### Интерфейсы

#### Desktop UI
- **desktop-ui** - Графический интерфейс на базе egui/eframe. Включает темы, различные view для отображения дизассемблера, графов, дампов памяти.

### Тестирование и фаззинг
- **fuzz** - Набор fuzz-таргетов для тестирования устойчивости парсеров и анализаторов. Использует libfuzzer. Тестирует:
  - Все парсеры (PE, ELF, Mach-O, COFF, DEX, WASM)
  - Дизассемблер x86
  - Лифтер IR
  - Анализатор импорта
  - Извлечение строк
  - YARA правила
  - Энтропию

## Зависимости и технологии

### Ключевые внешние зависимости
- **Capstone** - Дизассемблирование через FFI
- **sled** - Embedded база данных
- **egui/eframe** - GUI фреймворк
- **wgpu** - GPU вычисления
- **serde** - Сериализация/десериализация
- **nom** - Парсер-комбинатор для парсинга бинарных форматов
- **petgraph** - Работа с графами
- **libfuzzer-sys** - Fuzz testing

### Архитектурные особенности
- Модульная архитектура на основе workspace Cargo
- Каждое подмножество функциональности выделено в отдельный crate
- Использование промежуточного представления (IR) для независимости от архитектуры
- Поддержка множественных архитектур: x86, x64, ARM, MIPS, RISC-V
- Встроенный скриптовый движок для автоматизации
- GPU-ускорение для ресурсоемких операций
- Встроенная поддержка правил YARA

## Сборка и запуск
Проект использует стандартную систему сборки Cargo. Основные исполняемые файлы:
- `freakre-desktop` - GUI приложение
- `freakre-scanner` - Консольный сканер

Для разработки доступны примеры в crate `decompiler/examples`.
