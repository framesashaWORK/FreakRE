2. `func-sigs/src/fdb.rs` — `entry_index_key` теперь возвращает третьим элементом позицию
   ведущего фиксированного байта; `write_fdb` сворачивает её в `max_slow_pos` и пишет в заголовок.
   Добавлен регресс-тест `slow_ladder_survives_the_fdb_roundtrip`.
   Проверено: `cargo test -p func-sigs --lib` → 25 passed / 0 failed.
3. `freakre-ir/src/ssa.rs` — удалён дублирующий `op_is_commutative`, GVN использует
   `OpCode::is_commutative` (единый источник истины; теперь канонизируются и Eq/Ne).
   Проверено: `cargo test -p freakre-ir --lib` → 169 passed / 0 failed.
4. `cfg-builder/src/lib.rs` — в `connect_edges` ветка `ConditionalBranch` больше не делает
   `continue` при цели ниже `base_va`: сбрасывается только taken-ребро, fallthrough сохраняется.
   Добавлен регресс-тест `conditional_branch_below_base_keeps_its_fallthrough_edge`.
   Проверено: `cargo test -p cfg-builder --lib` → 18 passed / 0 failed.
5. Мойибаке в комментариях вычищен: 8 файлов автозаменой (265 фрагментов) +
   2 строки (`structuring.rs`, `desktop-ui/src/app.rs`) перерисованы вручную, рамка бокса
   выровнена по ширине соседних строк. Все `.rs` вне `fuzz/` теперь валидный UTF-8.
   Проверено: `cargo check -p decompiler -p freakre-scanner -p freakre-desktop
   -p freakre-server -p freakre-x86` → `Finished`.
